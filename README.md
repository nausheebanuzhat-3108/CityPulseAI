# 🏙️ City Pulse AI

## Intelligent Urban Activity Analysis and Zone Detection System

### 📌 Project Overview

City Pulse AI is an AI and Machine Learning based system that analyzes urban activity data to identify city zones, calculate activity levels, detect anomalies, and visualize results using an interactive dashboard.

---

## 🚀 Features

- Urban Activity Analysis
- Zone Detection
- Activity Score Calculation
- Anomaly Detection
- Interactive Dashboard
- Smart City Map
- Download Results as CSV

---

## 🛠 Technologies Used

- Python
- Pandas
- NumPy
- Scikit-Learn
- Streamlit
- Plotly
- Folium

---

## 🤖 Machine Learning Algorithms

- K-Means Clustering
- Isolation Forest
